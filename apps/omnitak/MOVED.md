# This iOS tree has moved

Active development for OmniTAK iOS happens in:

**~/Projects/OmniTAK-iOS/**

Do **not** edit files under `apps/omnitak/` here. Changes made in the monorepo
will not propagate to the public OmniTAK-iOS repo and will be lost the next
time we sync.

If you spot something that needs fixing, fix it in `~/Projects/OmniTAK-iOS/`
and commit there.

This tree is kept around for historical reference and the eventual
OmniTAK-Core release plan; the Android counterpart `apps/omnitak_android/`
follows the same rule (active dev moved to `~/Projects/OmniTAK-Android/`).
