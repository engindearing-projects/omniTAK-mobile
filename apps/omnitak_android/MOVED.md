# This Android tree has moved

Active development for OmniTAK Android happens in:

**~/Projects/OmniTAK-Android/**

Do **not** edit files under `apps/omnitak_android/` here. Changes made in the
monorepo will not propagate to the public OmniTAK-Android repo and will be
lost the next time we sync.

If you spot something that needs fixing, fix it in `~/Projects/OmniTAK-Android/`
and commit there.

This tree is kept around for historical reference and the eventual
OmniTAK-Core release plan; the iOS counterpart `apps/omnitak/` follows the
same rule (active dev moved to `~/Projects/OmniTAK-iOS/`).
